# 白眼通勤

現實裡瞪了沒用，這裡你的白眼是雷射。

上班路上，騎樓裡到處有人在抽菸。一路往前走，等他們冒煙時用白眼把菸瞪熄。肺活量扣光就結束，熄越多根，稱號越威。

## 操作

- **按住吸菸者的臉**：瞪他。集氣條滿了，菸就熄了。靠越近，集得越快。
- **按住空地**：往前走，只能往前。
- 電腦也可以用 → 前進、空白鍵瞪最近的人。

## 規則

- **看時機**：吸菸者會先滑手機，再點菸，冒煙了才瞪得熄。抽完他會亂丟菸蒂走人，就來不及了。
- **太早瞪**：還沒點菸就瞪，他會瞪回來，扣 1 格肺活量。
- **別瞪錯**：喝珍奶、含棒棒糖的人不是在抽菸，瞪錯扣 1 格。
- **回頭瞪**：有人從後面邊走邊抽時，左上角會出現警告，可以轉身瞪他。
- **連打**：老菸槍會瞪回來，騎樓聚會整群會一起瞪回來，要狂點畫面贏過他們。輸了扣 2 格。
- **別吸到**：站在煙裡會扣肺活量。騎樓空氣也會越來越差，肺活量會慢慢下降，要一直熄菸補回來。
- **清肺時刻**：肺活量集滿 9 格，一瞪就熄，打騎樓聚會也特別容易。

## 稱號

| 熄掉的菸 | 稱號 |

| 5～11 根 | 白眼見習生 |
| 12～21 根 | 騎樓白眼王 |
| 22～34 根 | 菸害終結者 |
| 35 根以上 | 騎樓死神 |
